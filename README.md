This is a personal website that has 5 pages: home, faith, study, projects and sport. The faith page contains some of my personal favourite resources for improving your faith. The study page contains some of my recommendations for studying and some helpful sites. the projects page is a start on my portfolio and I will add more projects as I make more and remember to take screenshots. The sports page contains some of my favourite sports and ones I would like to play.
I made this for Terra then realised it could be used as my CS50 week 9 homepage so changed the title.
The site has 2 modes: light and dark. You can change the theme by pressing the sun/moon button on the navbar.

Technology used: 
  - HTML5 – for the structure of the pages.
  - CSS3 – for styling, backgrounds and themes.
  - JavaScript – for the light/dark mode toggle.
  - Bootstrap – for the navigation bar, cards and responsive layout.

I made this project to get an intro to bootstrap and JS and because I think this site will be useful in the future for showcasing projects I have made/worked on.
I learned how to use some basic bootstrap classes and how to get elements and manipulate them with JS.
